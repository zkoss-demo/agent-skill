# Overview
An example project contains zul and java generated by agent skill [zul-writer](https://github.com/zkoss-demo/agent-skill/tree/main/zul-writer).

All zul and java code in this project is generated by the agent skill, **zul-writer**. To show the actual capability of the agent skill, I just fix some syntax error and make the generated code compile and run,  keep it as original as possible.

# How to run
maven is required.

`mvn jetty:run`
visit http://localhost:8080/ to see the zul pages.

# Screenshots to zul
If a zul is generated from a screenshot, it contains a comment at the top with the original screenshot file name. For example, `<!-- Generated from: ui-screenshots/enterprise kanban board.png -->`.
