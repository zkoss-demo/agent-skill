# Agent Skills for ZK Framework

Claude Code agent skills for ZK Framework development.

## Skills

### zul-writer

Generates ZK Framework ZUL pages through a structured 3-step workflow: clarify requirements, generate ZUL, and validate the output. Supports both MVC and MVVM patterns, ZK 9/10, and screenshot-to-ZUL conversion.

**Contents:**

- `SKILL.md`: The main agent skill definition and workflow instructions.
- `assets/`: Contains various ZUL templates (both MVC and MVVM patterns) and Java source templates (Composer and ViewModel) used as references by the AI.
- `references/`: Documentation and guidelines, such as UI pattern to ZK component mappings.
- `scripts/`: Scripts for validating the generated ZUL files against structural and formatting rules.

## Showcase

`zulwriter-showcase/` — a runnable gallery of ZUL pages generated by the zul-writer skill. See its [README](zulwriter-showcase/README.md) for details.

## Test Data

`test/` contains ZUL files for validating the `validate-zul.py` script:
- `valid/` — well-formed ZUL files that should pass validation
- `wrong/` — ZUL files with known issues (malformed XML, invalid attributes)

## Install

Symlink the skill to Claude Code's global skill directory (`~/.claude/skills/`):

```bash
./install-skill.sh
```

Or link it into a specific project (`.agent/skills/`):

```bash
./link-skill.sh
```
